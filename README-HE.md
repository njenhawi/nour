# בניית האפליקציה (APK) בלי להתקין כלום

1. היכנס ל-github.com, צור חשבון חינמי ולחץ New repository (שם חופשי, למשל kitchen-qc).
2. במחשב: חלץ את קובץ ה-ZIP, ובמסך המאגר לחץ "uploading an existing file" וגרור פנימה את כל התוכן
   (כולל התיקייה הנסתרת .github). ללחוץ Commit changes.
   אם התיקייה .github לא עלתה: Add file ← Create new file, כתוב בשם `.github/workflows/build-apk.yml`
   והדבק את תוכן הקובץ המקביל מה-ZIP.
3. עבור ללשונית Actions ← Build APK ← Run workflow (או שזה ירוץ לבד אחרי ההעלאה). הבנייה לוקחת 3-6 דקות.
4. בסיום, היכנס להרצה שהסתיימה (וי ירוק) ← למטה Artifacts ← kitchen-qc-apk. יורד ZIP, ובתוכו app-debug.apk.
5. העבר את ה-APK לטלפון (וואטסאפ לעצמך, Drive, כבל) ופתח אותו. אנדרואיד יבקש לאשר
   "התקנה ממקורות לא ידועים" עבור האפליקציה שממנה פתחת את הקובץ.

דרישות: אנדרואיד 10 ומעלה.
בנייה מקומית (חלופה): פתח את התיקייה ב-Android Studio ← Build ← Build APK(s).
אם הבנייה נכשלת: העתק לי את שורות השגיאה האדומות מלשונית Actions ואתקן.
